RU-001 — Cadastro de usuário

O usuário deve conseguir criar uma conta no sistema.

RU-002 — Login

O usuário deve conseguir acessar o sistema utilizando suas credenciais.

RU-003 - Login alternativo

O usuário deve conseguir logar através de formas alternativas de login

RU-004 - Painel de usuário (seção principal)

O usuário deve conseguir consultar e navegar pela base de livros.
O usuário deve conseguir realizar as ações: Ler e favoritar
O Usuário deve conseguir pesquisar um livro em específico
O Usuário deve conseguir gerenciar o perfil dele

RU-005 - Painel de usuário (Minha biblioteca)

Todo livro clicado para ler deve ser encaminhado para a seção pessoal do usuário
A seção pessoal do usuário deve listar todos os livros escolhidos para ler
A seção pessoal do usuário deve permitir as ações: remover e continuar

RU006 - Painel de usuário (Histórico)

A seção deve listar o histórico de livros lidos do usuário assim como as informações

RU007 - Painel de usuário (Favoritos)

A seção deve listar todos os livros favoritados

RU008 - Painel de usuário (Relatórios)

A seção deve mostrar um dashboard com o progresso de leitura do usuário
